4AI Coding 与答辩演示建议

AI Coding 协作建议

  • 先锁公共接口再并行：app.py/layout.html/tokens.css 三人开工前统一，冻结后各自只改自己的页面与路由文件，避免冲突。
  • LLM 调用统一封装：backend/llm.py 统一提示词 + JSON schema 校验 + 超时兜底；非结构化输出用规则/正则二次兜底。
  • 巡检与写盘加锁：后台线程 + 全局锁写 JSON，沿用"读取→校验→加锁写→刷新"闭环，防止并发写坏数据。
  • 零依赖图表：遵守 UI 规范禁外部库，折线/饼图用原生 SVG 手写。
  • 预留 mock 开关：无网络/无 Key 时用本地样例数据，保证演示不崩。
  • 每页自检：改完在白天/夜晚两主题各截一次图，核对对比度、表格可读性、窄屏布局。

答辩演示建议

  • 演示动线（对应题目"完整呈现"）：输入计划 → 自动拆解 → 安排时间 → 触发巡检 → 弹窗提醒 → 反馈延期 → 动态重排。
  • 准备一条"事故剧本"：故意让一个任务延期，现场展示"风险警示 + 自动重排"。
  • 紧扣 5 大评审关注点：拆解准确性、排期合理性、提醒及时性、交互体验、完整度——每条都点一句证据。
  • 用"依据说明"加分：主动说明"为什么这样拆 / 排 / 提醒"，回应可解释性。
  • 30 秒体验彩蛋：双主题切换 + 数据动画 + 吉祥物状态，快速拉体验分。
  • 讲清 Agent 工作方式：LLM 解析 → 规则排期 → 定时器巡检 → 反馈闭环，一句话说透架构。
