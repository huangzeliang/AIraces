1总则与全局约定

本章锁定"前提条件落地、交付形态、字段口径、全局交互"四条底座。后面各章不再重复，只写菜单差异。

1.1前提条件落地映射（对提示词 V1.1）

1开发时长 2h

全文按"2h 内可落地"裁剪：P0 保最小闭环，P1 提体验，P2/P3 视情况；不可落地的进第 5 章 Demo。

2MVP 优先

所有页面只保"输入→拆解→排期→巡检→提醒→反馈"闭环所需的字段，不引入非必要配置项。

3AI Coding 主力

字段键、控件、校验、按钮行为均写到"AI 可直接生成代码"的粒度；第 6 章附 AI 自测提示词模板。

4Flask MPA 交付

每页标注路由与归属文件；前端分层 templates/pages + static/css|js/pages，后端按 backend/ 路由模块拆分。

5本地持久化

统一"读取 → 表单校验 → 加锁写入 → 页面刷新展示"闭环，载体 data/users.json、data/plans.json，不引入数据库。

1.4全局交互规范（所有菜单遵守）

规范项统一规则
查询 / 筛选列表页统一「筛选条（chips 可多选）+ 关键词搜索 + 重置」；筛选即时生效（前端过滤或 GET 参数回传），URL 保留筛选态以便刷新/分享保持结果。
排序列表表头可点排序（优先级 / 截止时间 / 进度）；默认按「截止时间升序、进行中优先」。
分页数据 > 50 条启用分页（每页 20 条），否则不显示分页条。
导出列表页右上「导出」按钮，格式 JSON / CSV 二选（由 C 线 data_io 统一实现）；导出内容 = 当前筛选结果，列取数据字典；文件名 {菜单}_{YYYYMMDD-HHmm}.csv。
下载导出即触发浏览器下载（Content-Disposition: attachment）；导入页提供「下载模板」template_import.csv。
二次确认删除 / 取消 / 清空 / 覆盖导入 一律弹确认框（B4 组件），确认后才执行；破坏性按钮用警示色。
空态无数据时显示空态文案 + 引导按钮（如「去录入计划」）。
加载态异步操作按钮进入 loading 且禁用，防重复提交。
提示（Toast）成功=绿、失败=红、警告=橙；文案统一（"已保存""操作失败，请重试"）。
权限（模拟）view_role=普通用户 隐藏「导入 / 清理 / 删除他人」等管理操作；管理员 显示。仅演示，非真实鉴权。
主题 / 无障碍双主题即时切换并记忆；焦点可见（3px 描边）；尊重 prefers-reduced-motion。

界面交互字段

字段名字段键控件必填默认校验 / 控制规则

字段交互逻辑与控制规则

  • raw_text 输入时：实时更新右下角字数计数；达到上限（2000）后停止接受输入并高亮计数为警示色。
  • 点击「解析计划」：前端先做非空校验 → 不通过则聚焦文本域并提示，不发起请求；通过则按钮进入 loading 并禁用，POST /plan/parse。
  • 「填充示例」按钮：仅前端把示例文本写入 raw_text，不落库、不自动提交。
  • 解析成功：跳转 /plan/confirm?plan_id=xxx；失败：留在本页，以 toast 提示且保留已输入文本。
  • 一句话办事（A4）：提交 query → 意图识别 → 命中受支持查询/操作则返回结果或跳转对应菜单；不支持则给出可选项提示（不静默失败）。

异常与恢复

  • 解析超时 → 提示"稍后重试"，保留原文，可重复提交。
  • 网络失败 → 文本不丢，toast 报错。
  • LLM 返回非结构化 → 由 backend/llm.py schema 校验 + 规则兜底，失败时不落半成品数据。

字段交互逻辑与控制规则

  • 主题切换：即时生效并存 localStorage；刷新保持。
