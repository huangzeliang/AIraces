关键数据模型 · 任务表（tasks）——支撑拆解、派人与甘特时间线

开工前锁定：父 / 子任务同表自引用成树（对应 F-117 拆解、F-116 甘特）；owner 供 F-216 按人聚合负载，depends_on 与计划起止供 F-217 计算关键路径与热点阻塞。

字段类型说明
task_idstring主键，T + 序号
parent_task_idstring父任务 ID；空 = 顶层大任务，自引用构成拆解树与甘特层级缩进
plan_idstring所属计划 / 目标，向上可追溯到部门重点工作
ownerstring负责人（拆解到人）；F-216 个人负载按 owner 聚合
title / detailstring任务标题 / 交付标准
estimate_minutesint预计工时（分钟）；子任务合计不得超出父任务（拆解校验）
planned_start_at / planned_finish_atdatetime计划起止；甘特条左右端，子任务时间窗须落在父任务窗口内
due_atdatetime截止时间；临期 / 逾期预警用
status / progressenum / int状态机（待安排→待执行→进行中→已完成…）/ 0-100 进度
depends_onstring[]前置任务 ID；F-217 计算浮动时间与热点阻塞的数据源
delay_count / delay_reason / completed_at / created_at / updated_at—延期与完成留痕、审计字段（沿用现有任务表）
  • 拆解校验：子任务工时合计 ≤ 父任务工时；子任务时间窗 ⊆ 父任务时间窗；沿 parent 链回溯校验循环引用，禁止成环。
  • 层级与进度：建议 ≤ 3 层（大任务→子任务→个人任务），超限提示；父任务进度默认按子任务工时加权，可人工覆盖；子任务全部完成则父任务自动 100%。
  • 删除与回收：父任务删除时子任务上提为顶层（或级联取消）并留痕；子任务可回收 / 调整归属到其他父任务，甘特图随之重排。
