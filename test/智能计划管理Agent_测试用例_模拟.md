### 比赛执行节奏建议

| 时间段 | 动作 |
|:---|:---|
| 0–20 min | 三人锁定公共骨架（app.py、layout.html、tokens.css、data/*.json），不动业务代码 |
| 20–100 min | 按 A→B→C 线并行开发，每完成一个 P0 功能点立即跑该点用例（TC-001~TC-030） |
| 100–140 min | 跑端到端冒烟 TC-041，修复阻断问题 |
| 140–160 min | 跑 P1 用例（TC-031~TC-040），能过就过，过不了降级为静态演示 |
| 160–180 min | 出双主题截图、准备答辩话术，P2 项统一口径「进阶能力，演示级呈现」 |

> **红线**：若时间不足，优先保 TC-041 端到端冒烟链路。只要这条能跑通，答辩主流程就成立。
